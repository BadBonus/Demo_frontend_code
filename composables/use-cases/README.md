# Слой приложения (Use Cases)

## Назначение

Директория содержит composables уровня бизнес-логики. Отвечает за оркестрацию сценариев пользователя и связывание данных с UI.

## Зона ответственности

- Вызов методов фабрик `createXxxActions` из `#api` (shared/api)
- Запись полученных данных в хранилища Pinia
- Управление состояниями загрузки и локальными ошибками для компонентов
- Объединение нескольких запросов в единую бизнес-операцию

## Паттерн

```ts
import { createXxxActions } from '#api/xxx'

export default function useXxxFlow(
  actions = createXxxActions(useNuxtApp().$api)
) {
  // состояние, тосты, оркестрация
}
```

Для тестов actions передаются параметром. `use*` — только синхронно на верхнем уровне, до первого `await`.

## Правила и ограничения

- Запрещены прямые HTTP-запросы и вызовы `$api` / `$fetch` / `useApi`
- Напрямую импортируется и используется во Vue-компонентах и страницах
- Не содержит деталей сетевой реализации (URL/DTO — в `shared/api`)
